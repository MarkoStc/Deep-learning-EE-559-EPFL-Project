# Data card

## Civil Comments (default)

| | |
|---|---|
| Source | Hugging Face `google/civil_comments`, `train` split |
| Content | Public comments from the Civil Comments platform with crowd-sourced toxicity scores in [0, 1] and identity-mention scores |
| Label used here | `label = 1` when `toxicity >= 0.5` (`dataset.toxicity_threshold`) |
| Columns kept | `text`, `toxicity`, `label`, and the identity columns used for subgroup metrics |
| Size used | Stratified subsample of 50,000 rows (`dataset.max_samples`), then a stratified 70 / 15 / 15 split with seed 42 |
| Cache | `data/civil_comments_t0.5.parquet` (git-ignored) |
| Licence | See the dataset card on the Hugging Face Hub |

In the original run the subsample had about 8% positives
(`outputs/evaluation/all_metrics.json`: 600 of 7,500 test comments are labelled
hate).

Known issues: toxicity is a broader notion than hate speech, scores come from
crowd raters with their own biases, and comments mentioning some identities are
labelled toxic more often regardless of tone. That is why subgroup F1 is
reported.

## HateXplain (optional, `dataset.name: hatexplain`)

| | |
|---|---|
| Source | Hugging Face `Hate-speech-CNERG/hatexplain`, read from the Hub parquet conversion (`refs/convert/parquet`) |
| Label used here | Majority vote over annotators; *offensive* and *hate speech* both map to 1, *normal* to 0 |
| Status | The loader is unit-tested with faked Hub data only. It has not been run against the live dataset in this repository. |
| Licence | See the dataset card on the Hugging Face Hub |

## Synthetic (tests and smoke runs only)

Generated by `red_queen.data.SyntheticSource`: template sentences built from
neutral words. About 30% of rows contain one of two invented words (`zorblat`,
`vexnor`) and are labelled 1. It contains no real hateful language and no
personal data. Results on it only show that the code runs.

## Stress-case files

`runs/<id>/stress/{train,eval}/stress_cases.parquet` hold the original and
perturbed text, the action, and the Guardian's predictions before and after.
They contain raw hateful comments from the source dataset and stay in
git-ignored run directories. `stress_cases_sample.csv` next to them holds 100
rows with slurs masked.

## Handling

- Do not commit dataset caches or stress-case parquet files.
- Do not paste unmasked examples into issues, pull requests or logs.
